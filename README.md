# CSS Color Markers

A frontend development project built with **HTML5 and CSS3** to demonstrate practical CSS styling techniques, color theory, gradients, box shadows, and layout positioning.

This project recreates three colored markers—red, green, and blue—using HTML elements and custom CSS. Each marker features a cap, a sleeve, gradient effects, and carefully styled shadows to create depth and a realistic appearance.

## Project Overview

CSS Color Markers is a hands-on project focused on transforming basic HTML elements into visually appealing designs using CSS. It demonstrates how color values, gradients, borders, shadows, and positioning work together to create polished visual elements.

## Features

- **Three Distinct Markers:** Red, green, and blue designs with individually styled components.
- **Linear Gradients:** Uses `linear-gradient()` to create depth and a glossy appearance.
- **Custom Box Shadows:** Applies shadow offsets, blur, and spread to enhance visual depth.
- **Multiple Color Formats:** Demonstrates `rgb()`, `rgba()`, `hsl()`, and `hsla()`.
- **CSS Layout and Positioning:** Uses `display: inline-block`, borders, and positioning techniques.
- **Organized Styling:** Uses CSS classes to manage the appearance of marker components.
- **Separation of Concerns:** Keeps HTML structure separate from CSS presentation.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Git installed on your computer.
- A modern web browser.
- A code editor, such as Visual Studio Code.

### Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/Regalson001/Colored-Markers.git
```

**2. Navigate to the project directory**

```bash
cd Colored-Markers
```

**3. Open the project**

Open the project folder in your preferred code editor.

**4. Run the application**

Open `index.html` in your web browser to view the color markers. No build tools, package installation, or backend server are required.
